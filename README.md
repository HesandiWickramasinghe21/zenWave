# ZenWave – AI Powered Mental Wellness Support Platform

ZenWave is an AI-powered mental wellness support platform designed to provide **non-clinical emotional assistance** through intelligent conversation and adaptive relaxation features. The system helps users reflect on their emotions and receive supportive responses using AI technologies.

The project focuses on improving emotional awareness and promoting mental well-being through a **mobile-based digital platform**.

---

# Project Overview

ZenWave allows users to interact with an AI chatbot to express their thoughts and emotions. The system analyzes user input, identifies emotional states, and provides supportive responses generated by an AI language model.

The platform is designed as a **client–server architecture**, where a mobile application communicates with backend services and AI components through secure APIs.

---

# Key Features

### User Authentication

Users can create accounts and securely log into the system. Passwords are protected using hashing techniques and authentication is managed using **JSON Web Tokens (JWT)**.

### AI Chatbot

ZenWave integrates an AI conversational chatbot powered by **Llama2 (GGUF) through Ollama**. The chatbot generates supportive and context-aware responses based on user input.

### Sentiment Analysis

User text inputs are analyzed to detect emotional states such as:

* Happy
* Sad
* Anxious
* Stressed
* Calm

This helps the system understand the user's emotional condition and provide relevant responses.

### Emotional Support Interaction

The chatbot provides supportive responses that encourage reflection, emotional awareness, and positive mental well-being.

### Secure Backend Communication

The system communicates through **RESTful APIs** to ensure reliable data exchange between the mobile application and backend services.

# System Architecture

The ZenWave system follows a **client-server architecture**:

Mobile Application (Flutter)
↓
REST API (Node.js + Express)
↓
AI Services (FastAPI)
↓
Database (MongoDB / Firebase)
